# 2.2.3

**Fixes**
- Hummingbird feeder would not accept sugar: the sweetener tag's name had a typo. Fixed.
- Hummingbird feeder kept the glass bottle when your inventory was full. It now always returns it, or drops it at your feet.
- Capuchin monkey looked like it floated above your head instead of sitting on it. Fixed.
- Fabric 1.20.1–1.21: 11 recipes (animal dictionary, echolocator, stink ray, straddleboard, tendon whip and others) used item tags Fabric didn't define, so they couldn't be crafted and recipe viewers showed them as broken. Fixed.
- JEI showed "Uncraftable Potion" as the input of the mod's brewing recipes (1.20.1–1.21.1). Fixed.
- The Czech translation never loaded because the file had the wrong name. Fixed.
- Pet store compatibility now also works with Redomesticate, the 1.21.1 port of Domestication Innovation.

Forge still has not released a build for 26.3, so 26.3 remains Fabric and NeoForge only.

Needs CodxLib 1.6.0 or newer. Fabric also needs Fabric API.
